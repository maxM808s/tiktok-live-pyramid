# Shared gift artwork

Imported at the user's request from their `maxM808s/tiktok-live-battle` gift library, commit `afcecf2e94bc252b7b647ff00fb71d815c312d61`. This 314-gift catalog includes the IDs in their 154-gift boxing library. Neither source repository was modified.

`catalog.json` retains the source names, IDs, coin values, image paths, original source URLs and original verification dates. These are imported metadata, not a new verification of current TikTok prices, regional availability, or live TikFinity access.

Gift artwork and TikTok marks belong to their respective rights holders. The project's MIT code license does not grant new rights to those third-party images or marks. Original image provenance is retained in catalog.json; import revision and file integrity hashes are in assets/gift-library-source.json.

Only the local WebP copies are used by the game. No image CDN or catalog download is used at runtime. Images are data assets, never executed. The import checked every image's WebP format, dimensions and bytes.
